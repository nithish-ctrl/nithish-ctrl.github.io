# The Dream Realm Archive — Nithish R.

A Shadow Slave-inspired, Sunny-core portfolio for GitHub Pages: playful system messages, a dark dream-realm palette, and project write-ups presented as “Memories.”

## Files

- `_config.yml` — Jekyll / GitHub Pages configuration
- `index.md` — the actual homepage, written in Markdown
- `assets/css/style.scss` — custom styling (SCSS, not HTML)

No separate HTML files are required.

## Publish on GitHub Pages

1. Create a repository named **`nithish-ctrl.github.io`** under your GitHub account.
2. Upload these files and folders to the repository root, preserving the structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the Pages build to finish. Your site should appear at `https://nithish-ctrl.github.io`.

If you are replacing an existing site, back up the old files before overwriting them.

## Personalize before publishing

- In `index.md`, confirm your exact degree title and graduation details.
- Check each project description against what you actually built.
- Add direct repository links to individual projects when you have them.
- Add a resume link when you have a public PDF URL.
- Keep metrics only when you can verify them from your own experiment logs.

## Theme notes

The site uses the GitHub Pages-compatible `pages-themes/minimal` remote theme and overrides its appearance with `assets/css/style.scss`. The visual style is dark violet, mist silver, and shadow-black, with restrained glow and responsive typography.

The styling uses CSS only; the page content remains Markdown. The theme may take a minute or two to build after the first push.
